Why envguard?

Built for developers who want security without the bloat. No Docker, no external APIs, no telemetry — just a fast, auditable binary that catches secrets before they leak.

Zero Runtime Dependencies

Pure Python standard library. No pip install of heavy packages. Install via pipx, pip, or download the standalone binary.

14 Battle-Tested Detectors

AWS, GCP, Azure, GitHub, GitLab, Slack, Stripe, OpenAI, database URLs, private keys, JWTs, and high-entropy strings — all with configurable severity.

Entropy-Based Detection

Catches unknown secret types using Shannon entropy analysis with configurable thresholds. Finds secrets other tools miss.

Smart .gitignore Support

Respects .gitignore and .envguard-ignore for false-positive suppression. Line-level and file-level ignores.

Pre-Commit & CI Native

Drop-in .pre-commit-hooks.yaml and GitHub Actions workflow. Exit codes: 0=clean, 1=findings, 2=error.

Multiple Output Formats

Human-readable table, JSON for pipelines, SARIF for GitHub code scanning, JUnit for test runners.

Built-in Detectors

Each detector is tested against real-world secret patterns and validated for low false-positive rates.

Installation

pipx (recommended)

$ pipx install envguard
$ envguard --version

Isolated environment, auto-updates, no dependency conflicts.

pip

$ pip install envguard
$ envguard --version

Standard Python package install. Requires Python 3.9+.

Standalone Binary

$ curl -fsSL https://github.com/honeyamn10-source/envguard/releases/latest/download/envguard-linux-amd64 -o envguard
$ chmod +x envguard
$ ./envguard --version

No Python required. Linux, macOS, Windows builds available.

Docker

$ docker run --rm -v $(pwd):/work honeyamn10/envguard scan /work

Minimal Alpine-based image (~15MB). Use in CI pipelines.

Usage

Scan a repository

$ envguard scan .
$ envguard scan /path/to/repo
$ envguard scan . --severity high

Check specific .env files

$ envguard check .env
$ envguard check .env.production .env.staging
$ envguard check .env --format json

Output formats

$ envguard scan . --format table   # default
$ envguard scan . --format json
$ envguard scan . --format sarif   # GitHub Code Scanning
$ envguard scan . --format junit   # CI test reports

Ignore false positives

# .envguard-ignore
config/test.env          # ignore entire file
config/prod.env:15       # ignore line 15
*.test.env               # glob patterns
!config/real.env         # negate (do not ignore)

Exit codes

0  — no findings (clean)
1  — findings reported
2  — error (invalid args, I/O)

Perfect for CI: envguard scan . || exit 1

Configuration

# envguard.toml (optional)
[scan]
severity = "high"
exclude = ["*.test.env", "vendor/"]
entropy_threshold = 4.5

[output]
format = "json"
show_context = true

CI/CD Integration

GitHub Actions

# .github/workflows/secrets.yml
name: Secret Scan
on: [push, pull_request]
jobs:
  scan:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - name: Scan for secrets
        run: |
          pipx install envguard
          envguard scan . --format sarif --output results.sarif
      - uses: github/codeql-action/upload-sarif@v3
        with:
          sarif_file: results.sarif

Pre-commit Hook

# .pre-commit-config.yaml
repos:
  - repo: https://github.com/honeyamn10-source/envguard
    rev: v0.1.0
    hooks:
      - id: envguard-check
        args: ["--severity", "high"]
      - id: envguard-scan
        args: ["--format", "sarif", "--output", "results.sarif"]

Also available: pip install envguard && pre-commit install

FAQ

Does envguard send my code anywhere?

Absolutely not. envguard runs entirely on your machine. No telemetry, no network calls, no external APIs. Your secrets never leave your disk.

Can I add custom detectors?

Yes. Create a custom_rules.yaml and pass --rules-file. The rule format is documented in docs/custom-detectors.md.

How do I suppress a false positive?

Add a .envguard-ignore file with line or file patterns. Or use # envguard:ignore inline comment in your .env file.

What Python versions are supported?

Python 3.9, 3.10, 3.11, 3.12, 3.13. Tested on all in CI. No support for EOL versions.

Is there a VS Code extension?

Not yet. But you can run envguard check as a task or use the SARIF output with the sarif-viewer extension.

How does entropy detection work?

Shannon entropy per character. Strings >4.5 bits/char are flagged. Configurable via --entropy-threshold or envguard.toml.
